# Security Policy

## Supported versions

This is a community-maintained library. We apply security fixes to the **latest
released version** on Clojars. Upgrade to the latest release before you report
an issue.

## Reporting a vulnerability

**Do not report a security vulnerability through a public GitHub issue.**

Instead, report it privately by email to **jsavyasachi@gmail.com**, or through
GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
("Report a vulnerability" under the repository's **Security** tab).

Include:

- a description of the issue and its effect,
- the steps to reproduce it (or a proof of concept), and
- the affected version(s).

You can expect an acknowledgement in a reasonable time. After we confirm the
issue and release a fix, we publish the advisory with credit to the reporter,
unless you ask us not to.
